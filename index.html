MineBot

Set a mining job, press Start, and walk away. The mod stays on your client and plays with ordinary player actions, one per tick.

This page describes the mod as written in source. It has not been verified in a running Minecraft client.

Source on GitHub Install

01 What it is

MineBOT is a client-side Fabric mod for Minecraft Java. It is not installed on the server. You configure a job; the client then looks, walks, jumps, breaks, places, uses, and clicks chests. Breaks take real time. It does not send custom packets. That is why it works on Paper.

The server does not need the mod. 25×25 down to bedrock is only a built-in preset named Example quarry, not the only mode.

com.minebot.core is the task runner and does not import Minecraft. com.minebot.client is the Fabric tick loop.

One action per tick. Real break times.

02 What you configure

Any width and length. 25×25 is not a limit.

Area
Corners or coordinates. Stand on the first corner and press Corner A, then the second corner, or type the coordinates.
Depth
Bedrock, a Y level, or a layer count. Bedrock is never broken.
Stair
Off, or a clockwise border spiral: one block down per step, outer ring first, the tread column left solid to bedrock, two blocks of headroom.
Blocks
Mine everything, or list block ids. The obstruction toggle digs other blocks when they are in the way.
Chests
The deposit list is what goes into chests. The keep list stays on you. Search a radius, or mark a chest. If every chest is full, the job pauses and the status line says Paused: chests are full.
Survival
Eat, at a hunger threshold. Sleep when a bed is nearby at night. Torch spacing. Auto-craft a replacement pick from materials on hand. The tier is the best those materials can make: wood, stone, iron, diamond, or netherite.
Presets
Named presets save and load. A job that was running resumes after you die or restart the client. Example quarry is one preset, not a separate mode.
Controls
K opens MineBOT. Press Start, or run minebot start. minebot stop stops the job.

03 Example quarry

A built-in preset, not the only way to dig, and not a measured runtime. The footprint starts at the corner you are standing on.

Built-in preset “Example quarry”
Footprint 25×25
Origin The corner you are standing on
Depth Bedrock. Bedrock is never broken.
Stair On. Clockwise border spiral.
Mine Everything
Deposit Cobble, deepslate, ores
Keep Torches, food, wood, iron

Before you start

Place chests near the dig and fill them with torches, food, wood, planks, sticks, iron, and a pickaxe. Add any extra item ids you want kept to the keep list. Then set the job and press Start, or run minebot start.

04 Install

The jar goes in the client mods folder. The server does not need the mod.

  • Minecraft 26.3
  • Fabric Loader 0.19.5
  • Fabric API 0.163.0+26.3
  • Java 25

./gradlew build writes the jar to build/libs. Put that jar in the client mods folder next to Fabric API.

05 Develop

From a checkout of the mod. The task runner in com.minebot.core does not import Minecraft. 

./gradlew test
./gradlew build
